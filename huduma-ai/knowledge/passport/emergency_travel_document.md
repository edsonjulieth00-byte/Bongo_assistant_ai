# Emergency Travel Document (ETD)

Tanzania Immigration provides an Emergency Travel Document for eligible travel situations.

The official ETD online service allows applicants to complete an ETD application electronically.

The ETD system provides options for:
- A new application.
- Renewal of an expired document.
- Continuing or checking an application.

For an applicant using a passport number or applying for an ETD renewal, the completed application may allow the applicant to print the emergency document after completion.

For an applicant using a NIDA number or a guarantor identification number, the applicant is instructed to print the application form and submit it together with the required attachments to the nearest Immigration Office for processing.

The current official Immigration information states the ETD fee as TZS 20,000 in Tanzania and USD 20 abroad.

Applicants should follow the current ETD portal instructions for the documents required for their particular application.
