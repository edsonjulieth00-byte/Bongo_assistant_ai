# Tanzania Passport Application

The Tanzania Immigration e-Services portal allows an applicant to start a new passport application online.

For a new application, the applicant should:
1. Start a new application on the e-Immigration passport portal.
2. Enter personal information accurately and completely.
3. Save the Application ID and Reference ID for later use.
4. Enter previous passport information if the applicant has previously held a passport.
5. Enter guarantor and emergency-contact information as requested.
6. Attach the required supporting documents.
7. Review the information and confirm that it is correct.
8. Pay the applicable fee after receiving the payment Control Number.
9. Print and submit the completed application and supporting documents to the appropriate Immigration Office for processing.

The online portal also provides functions to continue an incomplete application and to check application status.
