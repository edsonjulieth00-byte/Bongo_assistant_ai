# Tanzania Passport Application Status

An applicant who has submitted a passport application online can use the Tanzania Immigration e-Services passport portal to check the status of the application.

The passport portal provides an Application Status option.

To continue an incomplete application, the applicant can use the Continue Application function and provide the Application Number together with the required basic information, including the Reference ID and phone number.

Applicants should keep their Application Number and Reference ID because these are used to continue or track an application.
