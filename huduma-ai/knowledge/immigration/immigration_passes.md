# Tanzania Immigration Passes

Source authority: Tanzania Immigration Services Department
Official sources:
- https://eservices.immigration.go.tz/online/web/pass/home
- https://eservices.immigration.go.tz/online/web/pass/apply
- https://eservices.immigration.go.tz/online/web/pass/continue

## Pass categories currently listed by the official e-Immigration portal

The official portal lists:
1. Business Pass.
2. Dependant Pass 1.
3. Dependant Pass 2.
4. Exemption Certificate.
5. Special Pass.
6. Student Pass 1.
7. Student Pass 2.

## Online application

The e-Immigration pass portal allows applicants to:
- Start a new pass application.
- Select a pass type.
- Provide email and application-center information.
- Continue an existing application using the Application ID and required security information.

The official portal directs applicants to the Pass Guidelines for the detailed requirements for each pass type.

## Important chatbot rule

Do not invent pass requirements, fees, validity periods or eligibility criteria when the current detailed Pass Guideline is not available in the knowledge base.

If a user asks for a specific pass and the detailed official requirements are not yet stored, tell the user that the current knowledge base contains the pass category but not enough verified detail to answer the specific requirements.
