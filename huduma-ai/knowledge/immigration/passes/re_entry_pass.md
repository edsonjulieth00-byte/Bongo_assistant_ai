# Re-entry Pass

A Re-entry Pass is an Immigration document associated with permission for an eligible person to leave Tanzania and return under the conditions of the pass.

Applicants should provide the documents required for the particular application.

These may include:

1. Valid passport.
2. Existing Immigration status or pass documentation.
3. Application or supporting letter where required.
4. Previous Re-entry Pass where applicable.
5. Prescribed fee where applicable.

The exact conditions, validity and eligibility should be confirmed using the current official Immigration guidance.
