# Tanzania Visa Application

Tanzania visa applications can be submitted online through the official Electronic Visa Application System. Visa on arrival is also available at official entry points for eligible travellers, but the Immigration Department recommends using the online application platform.

To start an online application:
1. Open the official Tanzania Electronic Visa Application System.
2. Select New Application.
3. Enter the required basic information, including email address, passport number and passport issue country.
4. Complete the online application form.
5. Upload the required photograph and supporting documents.
6. Pay the applicable visa fee online using an accepted payment method.
7. Submit the application.
8. Keep the Application Identification Number for tracking.

Applicants should apply through the official Tanzania Immigration website only.

A passport used for the visa application must have at least six months validity and at least one unused visa page.

After submission, applicants can track the application using the Application Identification Number. Visa notifications are sent to the email address provided in the application.

Applicants should wait for the Visa Grant Notice or approval notification before travelling. A Visa Grant Notice is not the final authority to enter Tanzania; the Immigration Officer at the point of entry makes the final entry decision.

Applicants should select the correct visa type and category. An application with the wrong visa type or insufficient information or attachments may be rejected.
